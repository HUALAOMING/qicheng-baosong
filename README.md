# 启程 5.0

基于既有版本增量升级，沿用原站点与用户数据库。

在线使用：https://hualaoming.github.io/qicheng-baosong/

[简短更新说明](RELEASE_NOTES.md)。已有 PWA 请在设置中检查应用新版本，再选择“保存并更新应用”，无需清除资料。

## 本地打开

解压 ZIP，进入 `qicheng-5.0` 文件夹，运行：

```sh
node scripts/serve.mjs
```

浏览器打开 http://127.0.0.1:4177/ 。本地端口与旧体验版隔离，可从设置导入原 JSON 备份。Node 仅用于本地预览，运行时无后端或第三方服务依赖。

另提供 `qicheng-5.0.0-offline.html`，Windows 可双击离线体验，以独立数据库保存内容。交付文件初始为空白资料，预览截图的数据不会写进去。可安装 PWA 需要 localhost 或 HTTPS；独立 HTML 是可编辑副本。

## 新功能在哪里

- 首页：统一深色光泽玻璃材质，浅色柔和阴影与边缘微光；加入近五天状态、未交卷练习继续入口。触控端用轻量渐变呈现光泽，减少模糊与布局动画。
- 目标院校：收藏后，在详情或卡片上直接“设为首页展示院校”，仍引用原校徽、校名及简称。
- 学习中心 → 每日阅读进度：选择日期、书目和页码范围，保存后可修改或删除。
- 个性化内容 → 阅读与学习记录：点击“用最新进度填入书名与日期”，随后可独立编辑，作者和心得等其他字段保留。
- 学习中心 → 学习日历：周/月切换，点击日期评估状态或设为首页倒计时目标。日历标语默认“今日事，今日毕。”，可自定义。
- 设置 → 多端资料接力：发送端生成完整 JSON，自行传输；接收端选 JSON 校验并确认替换。安卓、iOS、Windows 使用相同格式，显示本机最后保存、导入及源文件生成时间。不提供云同步或自动合并。
- 编排与导出 → 排版：可选简洁、细框或刊物强调线，默认简洁；导出文件页可开页码和独立目录。PDF/PNG/HTML/PPTX 目录使用实际分页，Word 使用动态目录和页码域，打开或修改后需更新整个目录；Markdown 不分页。

## 安卓体验与保存

页面切换保留外壳，不反复销毁菜单和顶栏；同页重绘保留滚动与光标，返回页面记住本次会话的滚动位置。每次冷启动仍固定进入首页。

修改答案只更新必要控件，防抖保存独立未交卷草稿，计时与导航不保存。后台隐藏时只提交真正脏的内容，重开可从首页继续。系统仍可能回收后台进程，PWA 无法阻止；本次增强恢复能力，尚未做实体安卓/iOS 后台实测。

原自动保存核心未改，真实内容、文件和设置变更继续保存；切页、菜单、临时标签、日历浏览、弹层和纯计时不保存。保存失败提示、完整备份和事务回滚保留。

## 数据与兼容

数据库名、版本和存储区不变，没有破坏性迁移；新阅读、日历和草稿使用独立记录。附件、自定义资源、倒计时、设置、答题数据继续进入完整备份。接收设备自己的保存/导入时间不从发送端复制，恢复成功后生成本机收据，失败保留旧值。

建议接收端也使用 5.0。导入完整替换本机用户资料，接收前可先备份；官方题库可重新获取，导入时保留接收端现有官方资源。新功能数据通过 JSON 和可编辑 HTML 一同保留。

题库、典籍和每日一句仍可离线 JSON 导入，设置提供样例与 AI 格式说明。英语正式题库 228 题、《管子》100 句保持原文。

## 检验
