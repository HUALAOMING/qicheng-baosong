## 5.1 更新

- 练习中心默认四个题库；导入 JSON 时选择归属，也可新建自己的题库。一个题库可合并多个题目包，支持删除；旧错题、收藏和成绩保留。
- 设置中的“保存与设备接力”统一提供立即保存、导出完整 JSON、导入完整 JSON。三个平台使用同一格式，导入确认后完整替换本机资料，不自动合并。
- 可编辑 HTML 副本放入高级工具，包含程序、用户资料及已安装资源；它使用独立空间，不与原 PWA 持续同步。
- 数据看板分为“资料与成绩”“练习数据”。信息栏新增考试月历，日程尚为空，支持今后导入、主动更新、分笔试/面试展示。
- 深色题库选中状态更清晰；修复帮助图标偏移及设置误展开信息栏。更新下载采用小批处理与重试，失败保留旧版并显示详情。

## 本地使用

解压工程 ZIP，进入 `qicheng-5.1` 文件夹，运行：

```sh
node scripts/serve.mjs
```

浏览器打开 http://127.0.0.1:4177/ 。Node 只用于本地静态预览；应用运行无需后端。可安装 PWA 使用 HTTPS 或 localhost，独立 HTML 是离线副本。

## 数据与离线

继续使用原 IndexedDB 名称和版本。修改内容、上传/删除文件和更改用户设置时保存；切页、菜单、临时标签、浏览日历和纯计时不保存。编辑后立刻切页仍完成待保存内容。

完整 JSON 包含个人资料、附件、设置、阅读/日历、倒计时、答题草稿和成绩、错题收藏、自建题库及自定义资源；不包含页面状态、程序静态文件和官方可重新获取资源。旧 Backup / Transfer JSON 仍可恢复。

英语正式题库 228 题、《管子》100 句保持原内容。已安装资源可完全离线使用；内容更新清单仅在主动点击时获取。考试日历资源为 0 项，没有预填真实或测试日期。
