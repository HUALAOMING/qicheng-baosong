# 启程 5.2.0

在 5.1 基础上增量更新，保留原数据库、安装地址与资料兼容。

[在线使用启程](https://hualaoming.github.io/qicheng-baosong/) · 原 PWA 更新方式：设置 → 检查应用新版本 → 保存并更新应用。无需卸载或清理资料。

本轮补充页面专属灯泡帮助、可切换的多梦想院校、跟手拖动的本周七句，以及三个主题与保存区域的外观打磨。仍为 5.2.0。

## 打开本地工程

在此目录运行：

```sh
node scripts/serve.mjs
```

浏览器打开 http://127.0.0.1:4177/ 。若同时保留旧版本，请给本版独立端口：PowerShell 中先执行 `$env:QICHENG_PORT=5270`，再运行上述命令，通过 http://127.0.0.1:5270/ 访问。应用无需后端服务，Node 仅用于本地静态预览。

另行交付的 `qicheng-5.2.0-offline.html` 是配套的空白独立离线程序，可直接打开；它与 PWA 使用不同的资料空间。若要从线上 5.1 继续，先在原应用导出完整 JSON，再在本版启动页选择“载入本地保存记录”。不同地址和浏览器不会自动共享资料。

## 5.2 功能

- 每日阅读进度以自由填写的章节为核心；仅日期、书名、作者、语言和章节必填。旧页码记录保留。同书自动汇成阅读纵轴，可按最近录入排序或按书筛选。
- 阅读经历单独录入，可自行撰写，也可从每日进度整合书名、作者、语言和日期；默认当天，可修改。全部阅读小记可一键整合为心得并继续编辑。
- 每日一句可选择本周七句并设定周一至周日顺序；可选不同典籍或句库，本周结束自动恢复默认滚动。
- 成绩曲线先选总分/科目，再选实际得分/得分率/排名。加权计算器按所选考试及权重自动归一化，分别计算总分与平均名次；缺失数值不会当成零。加权平均名次仅供参考，可能存在较大误差。
- 考试月历任意日期都可添加安排，支持院校、笔试/面试/其他、选填地点，以及编辑和删除。
- 学习中心新增自我介绍汇总，多版本、字词计数、大字复习、分钟秒换算、倒计时与超时计时。个人陈述可手选任意自我介绍复制正文，并新增选填小语种陈述。
- 导出排版独立设置分割线、纸色、背景图与各版块标题颜色；正文默认黑色。三档密度开关可拖动、吸附、键盘操作，保留原有细项微调。支持 HTML、PNG、PDF、可编辑 PPTX 和 Word。旧文档的黑白 Word 开关保留，需要彩色 Word 时关闭此开关。
- 设置中可直接复制给 AI 的完整题库生成指令。导入格式错误会给出提示并保留原数据。版本底部只展示系统版本与四个默认题库的更新时间。

## 自动保存、手动存档、缓存

自动保存沿用 IndexedDB 本机数据库，使用严格提交；修改后约半秒保存。仅浏览或纯计时不会持续写入数据库。它与离线程序缓存是两类存储。

菜单底部“手动保存”和设置中的“手动保存本地文件”会生成完整 JSON：支持系统文件选择器时直接写入所选文件，否则打开文件下载/分享窗口。请完成文件保存。文件包含用户资料、附件、设置、阅读、日历、自我介绍、未提交的自我介绍草稿、答题记录、自建题库等；官方可重新获取资源和程序本身不放入日常 JSON。高级工具中的可编辑 HTML 副本则额外包含程序和官方资源。

每次启动可选择读取本机数据库继续，或载入 JSON 文件。载入先校验、显示信息并确认覆盖，不合并两份数据。旧版 JSON 保持兼容。

“清除程序缓存”只删除当前安装路径的离线程序资源，保留数据库和外部文件，并提示先手动存档及重新联网；“清除本地数据”则经两次确认清空用户数据库。无论哪一种，已保存到磁盘的 JSON 不会被删除。
