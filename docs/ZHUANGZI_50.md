# 《庄子》50句：启程经典名篇资源

版本：1.0.0；整理日期：2026-11-04（Asia/Shanghai）。

选目和顺序严格沿用用户补充的50句清单：内篇36句、外篇11句、杂篇3句，共17篇。原文不夹带编号或出处，简释独立保存；保留原清单字词，统一为简体，使用现代标点。所选为节引，不宣称每条是完整段落。

## 下载与使用

- [下载 JSON](https://raw.githubusercontent.com/HUALAOMING/qicheng-baosong/main/data/resources/zhuangzi-50.json)。保存为 UTF-8 的 `zhuangzi-50.json`。
- 推荐：在原站点的“设置”中点击“获取最新资源”，确认应用显示的资源更新提示；完成后在“经典名篇”中选择“庄子”。
- 离线或手动导入：通过“经典名篇”的 JSON 导入入口选择本文件。手动导入属于 custom 资源，在线更新属于 official 资源；同 ID 的手动资源优先显示。如先手动导入，再更新官方资源，优先显示手动版本是既有应用行为。
- 应用版本不变，无需重新安装或清空数据。已下载资源存入本机数据库，后续可离线阅读。

## 兼容格式

依据 main 分支 33dadd6705beed950a6d9cf078f66fdc3f10e610 的 `js/resources.js` 中 `validateClassic`、`importResourceJSON` 和 `updateResources` 核对。

根对象仅使用 `schemaVersion: 1`、`book`、`passages`。`book` 使用 `id/title/version/englishTitle/subtitle`；`passages` 每条使用 `id/chapter/text/explanation`。书籍 ID 为 `zhuangzi`，段落 ID 固定为 `zhuangzi-001` 至 `zhuangzi-050`，后续修订不得因排序变化而重新编号。出处、链接和校记放入兼容字段 `explanation`，不添加会被校验器丢弃的自定义字段。

在线入口读取 `data/resources/manifest.json`，资源类型为 `classic`。本次只增加独立资源和清单项，不修改运行时代码、其他题库及内置 `data/classics.json`。后续内容修改须提高 `book.version`，并同步清单版本及实际文件的 SHA-256。

## 校对与异文

主要逐篇核对来源为[维基文库《庄子》](https://zh.wikisource.org/wiki/莊子)。各句简释末尾附对应篇目链接。简释为本次重新撰写，不复制现代译注；电子文本核对不等同于对某一纸本版本的校勘定本。

- 第4句保留清单“则其负大舟”；维基文库《逍遥游》作“则负大舟”。[《意林》引《庄子》](https://ctext.org/text.pl?if=en&node=566893)有“则其负大舟也无力”。两种读法均不默认为录入错误。
- 第5、11、49句保留“知”，不擅改成“智”；第8句保留“辩”，释为“变”。
- 第18句保留“胡蝶”“与”；第23句保留“指穷于为薪”，对“指”的分歧只作提示，不以“薪尽火传”倒改原文。
- 第32句是四友故事的节引，保留“相与为友”；不与后文三友故事“相与友”混淆。
- 第33句在《养生主》《大宗师》均见，依原清单归《大宗师》，不误判为错引。
- 第34句保留“佚”，释为安逸；第39句保留“虚”，注明同“墟”。
- 第42句是惠子发问，简释标明说话人；第50句是《天下》对庄周的评述，简释标明语境。
- 第47句依清单保留“过隙”；核对的维基文库正文作“过郤”，已逐条注明。
- 第48句保留“荃”，说明通“筌”；“蹄”为捕兔器，不误释为兔脚。
