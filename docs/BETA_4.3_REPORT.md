# 启程 4.3.0-beta.1 本地体验版

完成日期：2026-10-17（Asia/Shanghai）。只完成本地工程与检验，没有上传 GitHub、修改 Pages 或创建 Release。原 4.2.1 工程保留，149 个已交付文件与原 ZIP 逐字节一致。

## 本次功能

1. 答题题数改为手动输入 1–200 的整数。题目不足时只练习全部可用题，不重复抽取。随机、错题与收藏复练继续使用同一引擎。
2. 默认显示已用时间，可开启 1–180 分钟倒计时。采用开始时间计算实际经过时间，离开答题页面、后台挂起或返回后不会靠漏掉的 interval 次数计时。到时只提醒，保留答案，允许继续完成；仍由用户点击提交本组后统一判分。提交成功后冻结本组用时。
3. 首页以信息展示为主：可自定义的鼓励标语、梦想院校、目标倒计时、最近练习/成果和每日阅读分区。两个跳转入口缩小、下移至底部。沿用三主题，以清晰层次、文字可读性、即时按压反馈及 reduced-motion 改善交互；未引入新的动效库或强制玻璃视觉。
4. 梦想院校页面增加“首页展示的梦想院校”选择器，引用已有目标/收藏名称。主页读取现有校徽、校名、简称与城市数据，不建立重复的院校资料。所选目标移除时临时回退到仍有效的目标，不删除用户偏好。
5. 首页与设置均可修改加油标语，留空使用默认标语，提供恢复默认。
6. 设置里始终显示“检查应用新版本”。检查反馈区分离线、当前最新版、仍在下载、下载失败与新版已就绪；就绪后显示“保存并更新应用”。检查不保存资料；应用更新前等待真实编辑及独立数据写入完成，保存失败不激活新版。独立 HTML 会明确说明需在 PWA 中更新程序。
7. 略微增大提示、来源、练习状态、辅助标签等文字，大部分阅读性辅助文字为 14px 或以上。文档导出排版仍由原文档设置控制。
8. 设置“首页与每日一句”中可选句库或已有典籍。classic JSON 的原文直接作为每日阅读来源，按日期选段并链接到原句；无需复制或另做 quotes 文件。重导入同 ID 典籍会同步更新正文和每日阅读，未安装或空书目禁用；来源暂不可用时回退句库。

## 保存与兼容

原 autosave.js 未改，500ms 防抖、失败提示和保存队列保留。纯导航、菜单、临时标签、计时刷新及检查程序更新均不调用工作台保存。编辑后立即切页仍能落盘。计时每秒只更新必要数字，不重绘整个页面，不写入数据库；正式练习记录只在整组提交时写入。

数据库 qicheng-v4、版本 1、records 存储区、工作台格式 6、备份格式 1 均不变。新增 settings:home 独立记录保存标语、展示院校引用及每日阅读来源。quiz:record 允许新的手填题数，并增加可选 timing（开始时间、用时、时限）；无计时字段的旧记录继续可读。完整备份与可编辑 HTML 包含首页偏好和典籍绑定，恢复失败回滚逻辑保留。

默认本地端口 4175，用于与原 4.2.1 的默认本地端口分开。可从设置恢复 4.2.x 备份体验；本 beta 的自定义题数组和计时记录建议在本版中恢复，旧版的校验规则不覆盖全部新记录。线上正式版没有变化。
