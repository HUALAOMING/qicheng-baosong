# 启程 5.2.0 交互与外观更新验收

日期：2026-10-26。版本保持 5.2.0。基于第一轮5.2功能继续打磨，本轮完成后发布到原GitHub Pages地址。

## 本轮修改

- 灯泡按当前页面、编排导出的当前标签以及界面语言显示专属使用方式与备注；切页更新内容并收起旧页帮助。关闭和Escape返回触发按钮。所有现有菜单路由、典籍与院校详情均覆盖。
- 成绩页灯泡说明相对权重的归一化：例如20、30、50和2、3、5效果相同；加权值为分数乘权重之和除以权重之和，因此权重不必凑成100。计算器保留必要输入提示和“加权平均名次仅供参考，可能存在较大误差”。
- 首页梦想院校保持主校92px校徽和1.7rem校名（手机78px、1.35rem），右侧176px小卡显示其他收藏。点击小卡与主卡互换，主校持久化；只调整卡片DOM，未完成的首页表单保持。动画从当前呈现位置续接，连续点击可中断；失败回到已保存选择。
- 本周七句支持鼠标、触摸直接拖动。手柄跟随指针，邻居弹簧补位，释放速度衔接；支持方向键、Home/End、上下按钮及Escape撤销本次拖动。
- 布丁奶油纸、曜石石墨暖金、雾蓝三个主题统一表单、卡片、层级、间距与焦点。状态和手动保存按钮放进独立对齐的侧栏卡片，保存中/失败状态清晰。支持减少动态、减少透明和提高对比偏好。
