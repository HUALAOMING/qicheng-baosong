# 启程 4.3.1-beta.1 · 本地交付报告

日期：2026-10-17（Asia/Shanghai）。基于已完成的 4.3.0 beta 增量升级。只完成本地工程与交付文件，没有推送 GitHub、发布 Pages 或创建 Release。

## 实际完成

- 首页浅色模式采用更明显的卡片高低层次、柔和的多层投影、暖色渐变、较大的校徽和数字；每天鼓励、院校、倒计时、近期成果与每日阅读继续作为主要信息，快捷入口放在底部。
- 深色模式增加静态琥珀与靛蓝背景光、半透明玻璃、磨砂、高光边缘和分层阴影。无循环动画。高对比度、减少透明度或不支持背景模糊时回退实色；减少动态效果时取消装饰移动。最终窄屏截图发现相邻玻璃层的合成裁切，已通过明确文字与入口层级修正，并实测滚动显示。
- 菜单首页成为独立的房子图标入口。灯泡图标的学习中心分为“练习中心”和“阅读扩展”，后者直接显示已安装典籍。旧 explore、quiz 和 classic 路由继续可用。
- 编排与导出中的模块顺序改为原生 Pointer Events 跟手拖动，保留抓取偏移；相邻条目与松手归位使用小型临界阻尼弹簧，可从当前位置再次抓取、反向移动。手柄即时按压反馈，7px 拖动阈值，指针捕获、边缘自动滚动、触控、方向键、Home/End、Esc、取消手势与无障碍状态提示齐备。没有新增动效依赖。
- 数据看板保留原资料、成绩和分类图表，增加已提交练习的题数、组数、按题数加权的正确率、记录用时、分板块表现、最近七组及当前错题/收藏数量。旧练习无计时字段时不会报错，并注明用时覆盖范围。练习范围筛选仅用于当前界面。

## 保存、兼容与数据

数据库仍为 qicheng-v4，版本 1，records 存储区；工作台格式 6、备份格式 1 均不变。本次没有新建持久化字段或执行数据库迁移，统计从现有提交记录与标记计算。

原 js/autosave.js、js/storage.js、js/backup.js 与 4.3 beta 逐字节一致。防抖、保存队列、失败提示、完整备份和恢复回滚继续保留。导航、菜单、临时标签、计时、看板筛选、未落位拖动与取消拖动均不保存；仅真实顺序变更落位后调用原防抖保存。编辑后立即切页仍能完成保存。

正式英语题库 228 题（Grammar 118 / Vocabulary 110）、稳定题目 ID、中文空题库框架和《管子》100 句资料均未重制。原有上传、Markdown、地图、主题及各类导出能力保留。

使用隔离浏览器和合成资料验收，没有打开用户日常浏览器数据。原 4.3 beta 与 4.2.1 工程未修改；交付时与各自旧 ZIP 做逐项字节核验。本版默认本地端口 4176，与原 4175 及正式版来源隔离。需要资料时通过设置恢复旧 JSON 备份。
