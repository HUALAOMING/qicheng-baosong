# 启程 5.0 本地交付报告

日期：2026-10-22，Asia/Shanghai。基于 4.3.1 增量完成本地工程、离线体验 HTML、ZIP 和检验。未推送 GitHub、发布 Pages 或创建 Release。

## 实际完成

1. 页面切换保留 shell/sidebar/header，同页保留滚动、焦点和选区，回访滚动仅存在进程内存。减少进入动画、手机布局动画及模糊。答案原地更新，防抖写独立草稿，后台只 flush 脏内容。冷启动固定首页，可继续未交卷组，成绩仍仅整组提交产生。历史组保留摘要及最近完整快照，旧组离线按需复盘；范围读取避免各模块重复加载大附件。
2. 首页院校、倒计时、近期信息、每日阅读与五日状态使用统一边框、高光和阴影，取消校徽倾斜。桌面轻量模糊，手机静态渐变保留光泽，高对比度/减少透明度回退实色。无新动效依赖。
3. 收藏院校后可在详情及列表卡片直接设置首页展示，引用原院校资料。
4. 设置增加多端资料接力，复用完整 JSON，不改变文件格式。安卓/iOS/Windows 可自行传输后离线导入完整替换；展示本机保存、导入及文件生成时间，不自动合并。两独立设备间实测附件、自定义资源、设置、阅读、日历和草稿转移，错误文件不改数据或收据。
5. 原导出全部保留。可选细框/刊物强调线，默认简洁；页码开关、多页目录、标题实际落页和总页数一致。Word 用 TOC/PAGE/NUMPAGES 动态字段，打开或编辑后需更新整个目录。PDF/PNG 实物已渲染目视核对。PUB 按后续指示完全撤除。
6. 每日阅读记录日期、书目和起止页，支持新增、编辑、删除；最新书名/日期可一键填入个性化阅读录入，保留作者/心得，随后独立修改。历史分页减少手机负担。
7. 周/月日历每排七天，日期菜单支持四档状态、关闭和触控滚动；默认标语“今日事，今日毕。”可改。目标日与首页共用倒计时并高亮，首页显示近五天。无任务、排名或游戏化。

## 存储与兼容

qicheng-v4 数据库、版本 1、records 存储区、工作台格式 6、备份格式 1 不变，无清库或破坏性迁移。原 autosave.js 逐字节未改。

- 新增 journal:reading:<id>、journal:day:YYYY-MM-DD、settings:journal。
- 未交卷为 quiz:draft:active，成绩写入与草稿删除为同一事务；失败不产生半份成绩。
- 导出版本新增可选 pageDecoration/showPageNumbers；旧记录缺失时按原简洁/显示页码处理。
- meta:device 为本机保存/导入收据，不随 JSON/HTML 复制。真实用户写入时间在同一事务保存；导航、计时和只读不写。恢复成功生成本机收据，失败保持原值。
- 备份覆盖上传资料、自定义资源、首页、阅读、日历、答题/草稿、错题、收藏及其他用户数据。官方资源沿用排除规则，恢复保留接收端现有官方资源。救急导出会覆盖内存最新答案，即使草稿写盘失败。

原 4.3.1、4.3 beta、4.2.1 工程保留，交付与旧 ZIP 逐文件字节核验。全部检验使用临时隔离会话和合成资料，未操作用户日常浏览器数据库。
