# 5.2.1 题库与学习记录架构

题目身份始终为 `(bank.id, question.id)`。移动题目包仅修改目录归属，不修改题目 ID；答题记录、错题和收藏使用源题目包的身份，而非当前展示的目标题库名称。已有题型、任意科目、自建同级题库、资源包移动与删除等功能保留。

## 数据访问与首次迁移

- `@521:bank:meta:<origin>:<bankId>` 保存题库信息、按顺序排列的永久题目 ID 和内容修订标记。
- `@521:bank:q:<origin>:<bankId>/<questionId>` 每题独立保存题干、选项、答案、解析和来源。
- `settings:quiz-library` 仅保存题库目录及资源包归属。
- `quiz:mark:*` 保存个人错题、收藏状态，`quiz:record:*` 保存已交卷的题目和答案快照。
- `quiz:draft:active` 保存独立未交卷答案；`@521:quiz:overview` 是可重建的首页小摘要，不是学习记录的替代品。

首次进入题库相关页面时，旧的 `resource:official:*` / `resource:custom:*` 整库记录在同一事务内拆分为元数据及题目行，然后才删除旧整库记录。事务失败时保留原记录。ID、资源版本、题目顺序和学习记录保持原值。完整备份使用稳定的资源信封格式，恢复后重新执行该拆分，不把内部物理键暴露为备份协议。

存储层为完整导出和旧接口重建 `resource:*` 资源信封；普通 `getPrefix('resource:')` 不重建题库，避免启动时无意读取全部题目。

## 加载与增量写入

首页 `initializeHomeResources()` 只加载每日一句、考试日程和自定义典籍。首次迁移过后，首页练习卡片读取小摘要，不枚举全部练习历史。进入练习或设置时 `initializeResources({metadataOnly:true})` 只读取题库元数据和 ID 索引。

练习界面通过 `loadPracticeSample()` 对轻量 ID 索引抽样，按主键读取本组实际需要的题目，默认 10 题，最多 200 题；不为抽样读取整库题干和解析。练习 DOM 显示一题和最多 200 个导航按钮，不渲染整份题库。被删除题目的旧错题/收藏仍保留，但不计入可开始练习的范围。

`loadPracticeBank()`、无参数的 `initializeResources()` 和旧同步列表 API 为旧调用及导出保留完整加载能力。业务页面使用摘要或抽样 API，不应使用完整列表计算题目数量。导入和完整导出会暂时持有该次操作所需的题目数据；最大单个资源文件仍为 12 MiB、20,000 题。题目 ID 索引与目录元数据保留在内存中。

重复导入先按稳定 ID 比较规范化内容，仅写入有变化的题目、发生变化的元数据和目录。完全相同的重复导入不会启动写事务。单题解析修改只写该题和题库修订标记；不会重写未变题目，也不会修改个人学习记录。修订标记保证即使只有解析发生变化，多标签页冲突检查也有效。

## 预检、补丁与安全处理

`prepareResourceImport()` 不修改题库；返回的计划摘要包含新增、修改、未变、移除、答案/选项变更和相同内容计数。ID 重复、答案不存在、错误题型、缺失字段等拒绝导入；内容相同但 ID 不同的题目在摘要中提示，避免误删有意重复的题目。最终提交使用私有不可篡改的预检数据，调用者不能通过修改摘要偷偷改变要写入的题目。

设置中展示预检摘要并确认后才调用 `applyPreparedResourceImport()`。补丁格式示例：

```json
{
  "schemaVersion": 1,
  "patch": {
    "bankId": "my-pack",
    "baseVersion": "1.0.0",
    "version": "1.0.1",
    "questions": [
      {"id": "Q001", "set": {"explanation": "更正后的解析"}}
    ]
  }
}
```

`baseVersion` 和新 `version` 可省略。`set` 仅允许 `question`、`explanation`、`answer`、`options`、`source`；未指定字段保留。补丁不能修改 ID、题型、科目或静默新增题目。需要移除题目时显式给出 `deleteIds`，不能同时修改并移除同一个 ID。合并结果仍须经过完整题目校验。

答案或选项修改仅影响之后的新练习，旧成绩继续根据交卷时的完整题目快照显示，不重算、不改写。已开始练习保留原题快照。删除题目不删除历史成绩、收藏或错题标记；从新练习范围排除被删除题目。

每个预检计划绑定题库元数据的已观察修订号。等待确认期间其他标签页或另一任务更新题库，提交将以事务冲突失败，提示重新预检，不能静默覆盖。批量官方更新先下载并校验所有资源的 SHA-256、版本、ID 和内容，展示变化摘要，统一事务提交；某个下载失败或写入中断时全部保持旧版。

## 真实任务反馈

JSON 文件读取和 Worker 解析由统一任务模块处理。题库校验每 200 题让出主线程，报告已验证数量；无法测量的阶段显示不确定进度。预检完成只表示等待确认，明确尚未写入。提交阶段显示“等待事务提交”，仅在 IndexedDB `complete` 后显示任务成功；失败立即显示错误。

未交卷答案与首页小摘要在一次事务内提交，交卷将成绩、必要的错题变化、摘要和草稿删除一起提交。草稿写入捕获加载时的修订号；旧标签页的答案不能覆盖新标签页已提交的草稿。
