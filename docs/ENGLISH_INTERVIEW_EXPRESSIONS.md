# 英文面试表达积累：24句双语精选

版本 1.0.0，2026-11-04（Asia/Shanghai）。

六个主题各四句：语言与思维、判断与求知、学习与创新、自我与选择、合作与责任、行动与韧性。每条包含中英文、作者、作品与章节、核对链接、含义、适用问题、原创双语接话示例，以及必要的语境和译文说明。

使用时先回答问题，再择一句点明观点，接自己的真实事例。示例是表达练习材料，不代表使用者已经有相应经历。优先掌握与自己经历相符的几句，无需每题引用。

## 获取和入口

在[原启程站点](https://hualaoming.github.io/qicheng-baosong/)进入“设置 → 学习与答题”，点击“在线获取最新版资源”并确认。新资源安装后，“学习中心 / 阅读扩展”的既有资源卡片列表会自动增加《英文面试表达积累》，点击即可阅读、搜索及按六个主题筛选。

也可[下载 JSON](https://raw.githubusercontent.com/HUALAOMING/qicheng-baosong/main/data/resources/english-interview-expressions.json)，在“设置 → 学习与答题 → 导入本地 JSON”中导入。

“设置 → 启动与导航”中的“每日一句的来源”可选择《英文面试表达积累》，按日滚动展示。首页“自定义每日一句”的书目列表也可选择本资源，再选七句安排一周；已有本周自定义安排会优先于默认轮播，选择默认来源不会擅自删除已有安排。

两处共享同一份资源。英文、中文及作者一起放在 `text` 中，保证每日一句也有双语；出处和应用说明放在 `explanation`。后续更新提高 `book.version` 并同步清单校验值，段落 ID 保持不变。

## 格式和兼容

完全沿用当前 `schemaVersion: 1 / book / passages` 典籍资源协议。书籍 ID：`english-interview-expressions`；段落 ID：`interview-expression-001` 至 `interview-expression-024`。作为独立资源供现有积累阅读器使用，不覆盖原每日一句句库或《庄子》。阅读入口及两种每日一句选择均由现有代码动态生成，不需要更改应用程序或重新安装。

## 引文与译文

原句按各条标明的可访问作品、版本或档案校对，避免以名言聚合网站为唯一依据。孔子、老子的英文为本次译文，均已明确标注；其余中文由本资源译写。长句节引、历史拼写规范、文学角色台词和跨语境使用均在条目中说明。

特别注意：维特根斯坦的命题并非简单的词汇学习定律；奥威尔句子出自《政治与英语》；杜威采用可核对的《我们怎样思维》原句，不采用误引流传语；道格拉斯和金的句子保留争取权利的历史语境；莎士比亚句子标明卡西乌斯台词，不用它否认外部限制或归咎受害者。
