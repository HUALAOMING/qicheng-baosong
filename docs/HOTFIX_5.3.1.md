# 启程 5.3.1 热更新

日期：2026-10-31。基于已经发布的 5.3.0（含设置滚动修复），保持原站点地址、PWA 身份及本地数据库。交付方式为 GitHub 源码与原站点更新，不另交付单文件离线版。

## 题库层级与数据流

科目 → 题库 → 题包 → 题目。

- 题库是学习容器：四个默认题库与用户创建的题库同级。创建时选择英语、语文、已有自定义科目或新建科目，练习与管理使用同一科目目录。
- 题包是一次导入的资源身份。导入时选择目标题库；同一题库可容纳多个题包，重复导入相同包 ID 更新原包，保留本地修改冲突确认。
- 练习先选科目和题库，默认练习整个题库；下一级可选某一个题包，也可选择默认题库原有题目。
- 题库管理的题目列表仅按题库筛选，读取该容器内原有题目、后导入题包和手动新增题目。关键字覆盖题干、选项、解析、来源、分类与标签；分类可进一步限定。
- 列表跨包分页并保留每道题的来源身份。即便两个包使用相同题目 ID，也能分别修改、删除、收藏、记笔记，历史快照不重新评分。未交卷保护沿用来源身份。
- 题包移动和删除收纳在归属管理内，不与题库筛选并列。移动保留题目身份、笔记及历史。
- 导出整个题库时包含全部题包；为避免不同包同 ID 冲突，生成由原来源身份确定的稳定导出 ID。

5.3.0 的问题在于题库卡片已经累加导入包数量，但下方查询只读取同 ID 的原始来源。本次改为按容器的全部来源查询，无需重新导入旧题包。

## 导航与统计

侧栏“学习中心”增加“学习中心首页”，对应现有首页。学习统计统一进入“数据看板 → 练习数据”，旧统计入口兼容转入新页面。

统一统计支持最近 7 天、30 天和全部时间，展示练习组数、作答题次、不同题目数、正确率、待复习、收藏、计时、按题库/板块/分类表现及最近七组作答。只统计已交卷练习；重复练习计入题次，不重复计算题目身份。待复习与收藏反映当前状态，不随时间范围变化。

## AI 导入指令

“下载 AI 指令 md 文档”包含完整 JSON 格式、稳定 ID、答案和解析、导入归属及校验规则。“复制 AI 说明”只复制简短背景、用户目标与待补充需求，提示 AI 阅读随附 Markdown。用户将需求与 md 一并交给 AI，再把生成题包导入所选题库。

## 简历

正文颜色同时作用于字段名称与字段内容，标准色增加白色。支持全局设置以及单字段覆盖“名称与内容同一行 / 内容另起一行”，预览、Word、PDF 使用同一排版信息。

新增“青芽活力”和“砚金商务”两套完整模板，包含背景、色带、章节分隔及配色与间距。一键设置当前版本的外观并保留简历内容。Word 使用原生可编辑文字与表格，PDF 保留相应背景与分隔。

## 维护验证

运行 `npm run package` 刷新应用缓存清单，再运行 `npm run check`、`npm test` 及本次 `tests/*531-browser.mjs` 浏览器回归。`pwa531-browser.mjs` 使用已发布 5.3.0 提交作为旧版本，实测同源升级、旧题包/笔记/资料保留、离线重开、多窗口更新协调及失败缓存保护。浏览器验证使用隔离的合成资料，不接触用户日常浏览器数据。
