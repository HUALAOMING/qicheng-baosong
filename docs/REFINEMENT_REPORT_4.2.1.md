# 启程 4.2.1 修正与验收

本次针对用户实际使用反馈，在现有工程中增量修正，保留原有业务、上传文件、主题、导出、答题与备份能力。

## 保存

移除页面导航、菜单开关及分组的保存调用。图表筛选和文档选择作为临时显示状态；保存指纹也排除导航字段，避免手动保存或退出时误写导航变化。真实内容、文件、主题、语言和排版继续保存，沿用 500 ms 防抖、原写入队列、失败提示和备份恢复。切页不取消编辑的待保存任务。落盘的旧导航字段采用首页默认值，保持老格式可读，不持久化当前页面。

真实浏览器计数确认：导航、菜单及临时标签产生 0 次 current 写入；编辑后立即切页，产生 1 次写入且内容正确。上传文件、确认删除与修改排版均能落盘。

## 页面

设置和保存与备份合为普通设置页面，菜单左下角只保留一个设置入口。设置可以反复打开、滚动、切换主题和语言，没有设置弹窗或残留遮罩。Markdown、资源导入、恢复备份、备份数据、可编辑本地 HTML、安装及更新入口继续保留。

菜单按钮位于左侧。首页三页滑动栏已删除；应用与资源版本只在设置页最底部显示，品牌和启动界面的版本标记已移除。除设置外，各页面顶部显示当日原文，点击管子句子会展开原文阅读页、清除阅读筛选并定位到对应句段。

## 每日一句

将用户提供管子文档的 100 条原文逐条提取，不改字句，保留篇目出处和稳定句段链接。日历日期决定索引，同日刷新不变，跨日自动切换。旧 4.2 的官方空占位句库首次升级时使用随程序提供的本地资源填充，不请求在线 manifest；已有自定义句库和非空官方句库保留，在线资源仍只手动更新。

这里的每日自动显示发生在应用内，不申请系统通知权限，也不依赖推送服务器。

## 资源

同一个离线 JSON 入口按 bank、book、quotes 自动识别题库、典籍和每日一句。典籍支持稳定段落 ID、篇目、原文、简释，可填充预留书目，也可自动新增书目；题组同样自动进入统一答题引擎。所有自定义资源进入完整备份，可在 PWA 与可编辑 HTML 中使用。

设置内附格式要求、三份可下载 JSON 样例及可交给千问、DeepSeek、GLM 等 AI 的说明文档。导入完全离线，不需要绑定 AI 服务。AI 生成结果仍需核对答案和原文；应用负责格式验证和安全显示。

在线 manifest 扩展 classic 类型，并继续使用先完整校验、后原子事务替换的流程。打包工具自动收集 data/resources 内新增的题库、典籍或句库 JSON 进入清单，不需要修改前端代码。

## 存储兼容与检查

原数据库 qicheng-v4、版本 1、records 存储区、工作台格式 6 和备份格式 1 不变。仅为典籍增加 resource:custom:classic:{bookId} / resource:official:classic:{bookId} 键；旧资料不清理、不重建。旧版备份仍可恢复；新备份包含自定义题库、典籍和每日一句，排除官方资源与临时导航。

117 项自动化检查、29 项完整 Edge 浏览器检查全部通过。包含原业务与导出回归、全部答题模式、失败回滚、离线新窗口、可编辑 HTML、三主题与桌面/平板/触控布局（54 张页面截图），无意外控制台错误。证据见 TEST_EVIDENCE.json。

原文档、Desktop/Documents 工程及真实浏览器数据未修改。实测为 Windows Edge 和触控模拟，Safari 与实体移动设备未实测。
