# 5.0 本地修订：题库管理与更新可靠性

状态：本地完成，未推送、未部署；保存/接力/备份的整合方案等待用户决定。对外版本号仍为 5.0.0，尚未编排下一次发布。

## 题库行为

- 练习中心保留四个默认入口：英语语法、英语词汇、中国古代文化常识、汉语易错知识。
- 设置 → 题库与资源 → 导入本地 JSON：先校验，再选择默认或自建题库，点击确认才写入。
- 支持新建自定义名称的题库，并选择所属的四种板块之一。空题库可保留，不能开始空练习。
- JSON 的 `bank.id` 现在表示题目包身份；同一个题库可以容纳多个题目包。不同题目包的同名题目 ID 不冲突。
- 相同 `bank.id` 再次导入会替换该题目包，允许改变其练习归属；题目包自身的 subject/section 元数据沿用原有校验规则。界面会在确认前说明。
- 导入本地官方同 ID 的 JSON 时，转换为独立的 `local-pack-{官方ID}` 用户题目包，不覆盖官方内容，进入用户备份。
- 旧自定义题目包无需改写或清空，按原 section 自动出现在对应默认题库；错题、收藏仍按原始题目包 ID 与题目 ID 匹配。
- 可删除单个导入题目包，或删除自建题库及其中的导入题目。均须确认；默认题库不可删除。历史成绩、错题及收藏记录保留，已删除题目不再进入新练习；以后同 ID 再导入可重新匹配。
- 练习中心新增“管理题库 / 导入题目”入口。导入规则和下载给 AI 的说明已同步更新。

## 存储兼容

仍使用 `qicheng-v4` / version 1 / records，不升级 IndexedDB 结构。

新增一条用户记录 `settings:quiz-library`，保存自建题库定义与题目包归属；题目正文仍使用原 `resource:custom:{bank.id}` 记录。完整 JSON 与 HTML 副本均覆盖此目录。旧资料缺少目录时使用四个默认入口，不因读取或切页写入新记录。

原来的自动保存、备份、接力及 HTML 导出实现没有改动。题库增删仅写所需的资源与目录记录，失败事务不会发布新的内存状态。

## 应用更新

原流程一次缓存全部 116 项。本次改为每批最多 4 项，一批瞬时失败可重试一次；任意批次最终失败则删除本次未完成的新缓存并保留旧版。失败会向本应用页面报告具体文件组及错误。

检查时重新读取注册对象；浏览器返回 UnknownError / InvalidStateError / TypeError 时，在相同 URL 和 scope 上重试注册及更新一次。不注销、不清浏览器数据。有已下载待应用的版本时直接提供应用按钮，不再因额外联网检查失败而隐藏已下载更新。

这属于针对代码中可确定薄弱点的修复，不能据此断言用户安卓设备的真实根因。仍需用户安卓真机复测。客户端会保留可复制的技术信息，便于继续定位。

依据：[Chrome Service Worker 生命周期](https://developer.chrome.com/docs/workbox/service-worker-lifecycle)、[MDN updateViaCache](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerRegistration/updateViaCache)。大批并行对该用户设备的影响属于待真机验证的推测。
