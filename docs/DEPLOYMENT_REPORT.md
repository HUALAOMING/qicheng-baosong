## 安装与旧版更新

Windows Edge / Chrome 打开上述 HTTPS 地址，点击地址栏安装图标，或在浏览器菜单选择安装应用。应用设置也保留“安装启程”入口。等待设置中显示“离线资源已就绪”后即可断网启动。

原用户联网打开相同地址，发现新版后，在原设置中点击“保存并更新应用”。未显示提示时，可关闭应用后重新联网打开，等待更新下载完成。更新前会先保存资料，不要求清除网站数据、卸载应用或重新建立资料。

仍使用原数据库 `qicheng-v4`、版本 1、`records` 存储区、工作台格式 6 和备份格式 1。官方资源、自定义资源和用户资料按既有 4.1 设计分开保存，未重建数据库。
