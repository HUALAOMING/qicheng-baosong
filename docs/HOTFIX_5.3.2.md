# 启程 5.3.2

日期：2026-11-04（Asia/Shanghai）。沿用原 GitHub Pages 地址、PWA 身份、本机数据库与安全更新流程。

## iPad 可选输入

奖项类别、经历/实践/成果类别、语言、阅读书名、手动考试院校等字段原来通过 `input[list]` 交给系统原生 datalist 弹出建议。奖项的输入事件仅更新草稿和安排保存，没有逐字重绘。iPadOS 的系统建议列表存在独立的覆盖、拦截输入回归，参见 [WebKit 305719](https://bugs.webkit.org/show_bug.cgi?id=305719) 及 [273327](https://bugs.webkit.org/show_bug.cgi?id=273327)。这是定位到的触发路径；不将模拟视口测试称为用户实体 iPad 上的复现。

统一替换为保持原输入节点的自由输入框，旁边“选择”按钮显式展开候选项。退格、连续键入与输入法组合期间不自动展开；支持方向键、Escape、点击外部关闭。使用同一数据源及原保存事件，选项不会限制自定义文字，动态插入的书名和考试院校输入也使用此组件。

## 照片裁剪与旋转

在原图上拖动四角、四条边调整范围，拖动框内移动；支持自由、原图、证件照、方形、圆形及自定比例。移除位置与缩放滑块。支持左右90°旋转、角度数字输入与一度微调，可校正歪斜后裁去空白边。

图片仅在打开编辑器时解码一次；拖动只更新选框，不逐帧解码原图。触控使用 Pointer Events 和指针捕获，并处理取消与多指干扰。键盘可移动选框及边框。应用后保存归一化矩形和旋转角度，取消不写入；原图二进制保留。

原 x/y/zoom 裁剪继续兼容。备份验证接受新增的可选 `rotation` 与 `rect` 字段，并检验角度、尺寸及边界。头像、记录配图、文档预览及导出复用同一裁剪画布；旋转和裁剪不以CSS外观代替实际输出。旧版应用不认识新字段，升级后应继续使用5.3.2及后续版本。

## 50句双语积累与后续导入

《英文面试表达积累》从24句增至50句，资源版本由1.0.0提高为1.1.0。原001—024的段落ID、原文和解释保留，新增025—050。继续用于阅读入口、默认每日一句与每周七句计划；原已选句子的身份不变。阅读器保留解释中的换行，双语及应用说明更易阅读。

完全沿用典籍 JSON：`schemaVersion`、`book`、`passages`，没有第二种导入协议。设置 → 学习与答题 → 导入本地 JSON。相同 `book.id` 更新同一集合，须提交更新后的完整段落数组；不同 `book.id` 新增独立入口。后续扩展不重新编号已有段落。示例：[可导入模板](templates/interview-expressions.json)。手动导入资源优先于同ID官方资源，此为既有规则。

## 更新步骤

原已安装PWA：设置 → 更新与离线 → 检查应用新版本，下载完成后保存并更新。随后在“学习与答题”点击“在线获取最新版资源”，将已安装的官方24句更新为50句。新安装及尚未安装此集合的用户也通过资源更新获取。无需卸载或清理本机资料。

## 验证口径

发布前运行 package/check、完整 Node 测试、触控视口专项、同源PWA升级/离线/多窗口回归及受影响导出验证。视口与指针模拟不等于实体 iPad/iPadOS 验证。具体结果记录于本版验收文件。
