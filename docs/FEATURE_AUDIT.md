## 文档与设置

- 界面：布丁奶油、黑橙、蓝图三种配色；中文/English；折叠侧栏、导航分组。
- 文档：五种原有配色及黑白；强调色/完整背景/纯白底；横纵 A4、中英标题、页边距、字号、行距、模块间距、紧凑/标准/舒展预设。
- 每份文档独立保存名称、目标、用途（简历/阅读档案/自定义）、文件名、模块顺序、禁用模块、排除条目、字段选择、补充表述、标题、分页和模块标题样式。
- 头像：是否导出、尺寸、方形/圆形/证件照/自定义比例；照片：随文/文末/隐藏、每行数量、选择、顺序、说明与关联。
- Word：黑白、是否包含照片；PPT：可编辑文字或整页图片；目录开关、导出前检查与分页预览。

- 保留原版中文/拉丁字体与 docx、pdf-lib、JSZip、fontkit、PptxGenJS 导出库；没有添加运行时第三方依赖或 CDN。
- CSS 只调整文件位置与源码排版。对去除排版空白后的声明序列做了完整比较，顺序和内容一致；PWA/备份/故障页样式单独追加。
- 新增普通 App 图标、maskable 图标、Apple 图标，沿用原 Logo 的门框和向上路径构形。
- 当前 Service Worker 预缓存 100 个运行资源。备份、文件下载及本机数据库不进入 Cache Storage。
- 外部官方招生页面、百科、地图数据来源链接需要网络；内置资料、地图、编辑、保存、文档生成、备份与恢复独立于这些链接。

## 原有流程保持

院校浏览/收藏 → 基本信息与资料录入 → 收录记录并保留草稿 → 分类或自由整理 → 图片/文件统一管理与关联 → 创建独立文档版本 → 选择字段/内容/照片 → 排版与检查 → 分页预览 → 导出并保留导出历史。

读取当前新版只有一个入口；没有历史版本转换器、账号、云同步或后台数据库。
