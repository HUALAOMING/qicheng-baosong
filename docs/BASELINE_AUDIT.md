## 集成与回归注意

1. `js/events.js` 是各模块控件绑定协调器；新增渲染模块须一并接入绑定，否则重新 render 后控件不会工作。
2. `scripts/package.mjs` 显式列出便携 HTML 的全部 JS；新增模块未纳入会报错。它还显式列出 CSS 和六份静态数据，新增文件需纳入对应内联规则。
3. `js/data.js` 同时支持 fetch 与 `QICHENG_STATIC.data` 内嵌数据；新增题库不能只支持联网 fetch，否则会破坏完整 HTML 副本的无网络运行。
4. 独立 HTML 的打包方式会去掉 import/export 并把模块放在同一闭包，新增顶层名称应避免与原模块冲突。
5. 完成运行资源变更后需重新打包，刷新便携 HTML、Service Worker 资源列表与缓存版本；静态题库应可离线读取。
6. 原功能快照比较 `workspaceHTML`。保留原断言；若改动原页，应解释必要差异，不应以删除快照来掩盖功能损失。
7. 用户数据须继续使用原保存/事务恢复链路；旧备份缺少新增字段时应兼容默认值，不丢弃已有记录、附件、文档版本或草稿。
