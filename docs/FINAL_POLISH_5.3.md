# 5.3.0 首页与体验优化记录

本轮在原 5.3.0 工程上修改，保留原有离线和学习功能。未发布或上传。

- 首页卡片可配置，配置独立保存；梦想院校最多展示五所，可右键、触摸长按或使用按钮编辑展示与主要院校，并与院校页面同步。
- 计时器以绝对时间计算倒计时及超时，支持暂停、重置、放大和本地持久化；备份、恢复及更新会等待相关写入。
- 编辑器搜索仅搜索当前版本，其他页面保持全局搜索；搜索结果使用独立浮层。
- 外观仅提供浅色和深色；旧蓝色界面设置迁移为浅色。导出文档的配色是独立配置。
- 49 所院校均增加建校信息和来源；北京大学标注暂无正式校训，深圳北理莫斯科大学校训标注待核实。部分来源为百科，推广前建议逐校对照学校官网复核。前身、合并和更名年份按所注口径解释。
- 首页学习概要使用局部刷新，避免后台保存或跨标签页更新时重绘并丢弃未提交表单。

## 验证

2026-10-30，本地 `npm test` 302 项通过，0 失败；`npm run check` 完成语法、资源路径和缓存哈希检查。`npm run test:browser:5.3` 使用本机 Edge 无头执行现有编辑、导出、学习、搜索、存储、升级和单文件离线回归。额外的 `tests/home53-browser.mjs` 和 `tests/home53-portable-browser.mjs` 验证首页设置、五校选择、计时器超时与刷新；后者断言没有 HTTP 请求。旧首页专项 `tests/home-polish52-browser.mjs` 的五项检查通过，包括切换院校时未提交表单保留。

测试使用隔离的合成资料。触摸和移动端使用浏览器模拟，没有实体 iOS、Android 或安装后的 PWA 外壳验收。先前性能报告是先前版本的实测，并非本轮性能复测。
